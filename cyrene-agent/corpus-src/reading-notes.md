# 读翁法罗斯时发现的东西

> 边读边记。每条的定位都写清楚，方便回查。

## 一、`？？？` 是她 —— 比她自报的名字更早

**发现处**：第一章「落木逐火英雄纪」，任务 `1040101` 和 `1040104`。

全篇 31 条 `？？？`，其中 **6 条是她的**。判别靠**句式**：她的句子是碎的，
2～6 字一顿，没有连接词；其余 25 条是别人流畅的长句、小伊卡的「呜嗡」、银狼的台词。

```
L127   迷……                                    ← 她第一次出声
L615   …谁？是谁？你…我…我是谁？
L616   …核？星？谁？你…我…我是谁？
L617   …睡觉？好？不好？你…我…我是谁？
L618   …碎了。迷失。想要…完整。
L918   你是？我是…是谁？
L919   疑惑…相同。答案，未知。
```

**L127 的上下文**：

```
124  好像有声音…
125  嘘，有动静。
126  谁在偷看我们？
127  【？？？】迷……                              ← 没说完整
128  【丹恒】…有人在附近？小心点，拿起武器。
```

「迷……」是「迷迷」的第一个音节。她**没有说完**，被丹恒打断了。

### ⭐ 她最早的语言是「回声」

L615–617 三条，逐条对应玩家前一句说的词：

| 玩家说 | 她回声 |
|---|---|
| 告诉我**谁** | …**谁**？是谁？ |
| 是你吗，星**核**？ | …**核**？**星**？谁？ |
| 别吵吵，让我好好**睡觉**！ | …**睡觉**？好？不好？ |

**她把刚听到的词捡起来，变成一个问题。** 而「你…我…我是谁」每次都原样重复——
她在借别人的话确认自己是谁。

L618 `…碎了。迷失。想要…完整。` 不是回声，是她自己的状态。

### 这解释了她角色故事·四的开头

> 「迷……」
> 「？」
> 嘻，故事的开始，还真是个充满悬念的相遇呀。

游戏里那句「迷……」是**被截断的**；角色故事里补上了后半——她其实问了「？」。

## 二、导出文件的顺序不是剧情顺序（已知缺陷）

`amphoreus-story.md` 里，**玩家选项和 NPC 台词是错位的**：

```
13: 　　被她看穿了。          ← 玩家的选项，却排在前面
14: 　　不能让她得逞。
…
28: 【帕姆】各位乘客请稍候，航线会议马上开始。   ← NPC 才该先说
```

**原因**：抽取时是按 `Story/Discussion/Mission/*.json` 的**文件顺序枚举句子 ID**，
而那些文件存的是**分支结构**。展开成平铺之后，分支之间的先后关系丢了。

**后果**：读起来像台词被打乱了；但**内容的完整性和归属是对的**（没有漏句、没有错配说话人）。

**修的前提**：要按 `OnStartSequece` 里的 `TaskList` 顺序走，而不是枚举 ID。
那需要重写抽取那一段。**目前没修**，因为读取时靠上下文还能辨认。

## 三、玩家选项看起来像旁白（同源缺陷）

导出格式里：

```
**【说话人】** 台词          ← 有说话人
　　台词                     ← 没有说话人 → 渲染成旁白
```

但**玩家的选项**也没有说话人，于是和**真正的旁白**混在一起，分不开。

**判别线索**：选项通常**连续出现 2～4 条**、每条都很短、而且**位置紧挨着它触发的回应**。
这可以拿来分离，但没做。

## 四、ingest 的质量过滤器会丢掉她早期的句子

`tools/ingest.mjs` 有一个 `isFragment()` 检查，把以「…」开头或没有句末标点的行
判为 `continuation-fragment` 丢掉。对一般语料这没错——那是被截断的半句话。
**但她的碎句不是截断**，那是她那个阶段的说话方式：

  …谁？是谁？你…我…我是谁？
  …核？星？谁？你…我…我是谁？
  …碎了。迷失。想要…完整。

加 `--keep-noise`（它同时关掉两个质量过滤器）之后，从 488 条涨到 507 条，
多捞回 19 条**真台词**。其中一条自己说明了整件事：

  …啊，对哦！人家竟然能蹦出完整的句子了！

她注意到了自己从碎句变成整句。这是那条弧的自我确认。

**代价**：`--keep-noise` 也会留下界面文字。她的话里几乎没有，所以可以接受。
换成别的角色要重新判断。

## 六、她能说出自己「不是什么」，说不出「是什么」

**发现处**：第一章 `1040110`（L1111–1135）。这一段也是之前那条碎片的完整上下文。

**第一次**：她刚出场，只说了——

```
【？？？】迷……                    ← 被打断
```

**第二次**：玩家调侃「开局一人一狗…」，她反驳——

```
1129  【迷迷】人家不是狗！也不是宠物！是……
```

**又断在同一处。** 两次都是自我定义说到一半停住。

她能清楚地说出自己**不是**什么（狗、宠物），一到「是什么」就没了。
后来她退让成「是个可爱的小动物呀」——那是回避，不是回答。

### 同一段里还有几件事

**她没注意到自己变了**：

```
1111  …你不口吃了？!
1112  原来你说话能连成整句啊！
1122  …啊，对哦！人家竟然能蹦出完整的句子了！
```

**是玩家先发现的。** 她 answer 的时候才意识到。

**她有毛**（1131「照得身上的毛都暖洋洋的」），
**她被叫宠物会不高兴**（1129），
**她对自己一无所知**（1127「有关自己的事，还是记不起来一点呢。真头疼呀」）。

**配音那条是元玩笑**：

```
1114  你怎么没配音啊？
1125  又不是人家想这样的，你不许评价！
```

### ⭐ 这一段和角色故事·二对得上

角色故事·二里她对着「桃子」问了一串问题：

> 金发的织者明明能够做出最美的衣服，为什么不让她看得见？
> 狮子一样的王子不会死亡，所以就必须一遍遍地受伤？
> ……
> 还有，桃子，你每次离开之后，都去哪里啦？

**同一种状态**：她看得见别人的处境，看得见自己的困惑，
但**问到「我是谁」就没有下文**。这不是编剧的疏漏，是贯穿的写法。

## 七、她的语言是怎么长出灵性的 —— 游戏自己给了机制

**发现处**：第二章「门扉之启，王座之终」，`1040204`（L1302）。

```
1302  【遐蝶】说来也真是神奇…尼卡多利一战后，它的声音仿佛就有了灵性。
```

**尼卡多利那一战是分界点。** 在这之前她只会回声和碎句；在这之后她能说整句了。

这和第六节那条对得上：

```
1111  …你不口吃了？!
1112  原来你说话能连成整句啊！
1122  …啊，对哦！人家竟然能蹦出完整的句子了！
```

**玩家先发现的，她自己没察觉。** 而游戏把原因放在遐蝶一句轻描淡写的旁白里，
没有解释为什么，也没让任何人追问。这个处理很克制。

### 「小狗」那件事的第三次

```
1307  【缇安】…还有…粉色小狗？
1303  【迷迷】太失礼啦！怎么能对女孩子说这种话呢？
```

这已经是第三次纠正称呼了：

| 第几次 | 场景 | 她的回应 |
|---|---|---|
| 一 | 玩家问「所以你其实是只小狗？」 | 宠物，不是！ |
| 二 | 玩家说「开局一人一狗…」 | 人家不是狗！也不是宠物！是…… |
| 三 | 缇安叫「粉色小狗」 | 太失礼啦！怎么能对女孩子说这种话呢？ |

**第一次是否认，第二次是卡住，第三次她换了个说法——「女孩子」。**
从「不是宠物」到「是女孩子」，她第一次给自己找了个可以用的词。
但她仍然没有说清**是什么**，只说清了**该怎么称呼**。

### 顺带验证了 `？？？` 的归属

L1381–1383 那三条 `？？？`（「吾就承蒙夸奖了」「着急可吃不得热燕麦粥哪」）
就在这一段里，紧接着 L1386 显示说话人是**卡吕普索**。
句式是流畅的长句——和她的碎句完全不同。**当初把它们排除在外是对的。**

## 八、第三章：她开始有「自己守的规矩」

**发现处**：第三章「走过安眠地的花丛」，`1040301`–`1040309`（L1699–2187）。

### 她在试自己的嗓子

```
1756  　　你怎么会说话了？!
1757  【迷迷】你看你看，不知道为什么——人家能说话啦！喂喂喂，一二三，喂喂喂，一二三……
1759  【迷迷】好可爱的声音！一定是因为收集了许多记忆，人家的成长远超预期！
```

**「喂喂喂，一二三」——她在测试自己能不能说话。** 这是全篇最像小动物的一处。

而她对原因有**自己的说法**：「因为收集了许多记忆」。遐蝶说的是「尼卡多利一战」。
**两个解释不一样，游戏没有说明哪个对。**

### 「小狗」那条线在这里收了

```
1699  【迷迷】嘿嘿，人家也借着你的光，从「小狗」变成「圣兽」啦。
```

第四次提到这件事，但**这次她是高兴的**。阿格莱雅称她「圣兽」，她说功劳要记在开拓者头上。
从「宠物，不是！」到「是……」（卡住），到「是女孩子」，到**笑着接受「圣兽」**——
这条线走了四步，最后落在一个玩笑上。

### 她开始划底线

```
2131  【迷迷】用归用…人家可要约法三章，我们回到过去不是为了偷东西。
```

**这是第一次她主动立规矩。** 之前她只回应别人，这里她先说了条件。

### 她嫌自己不够强

```
2156  【迷迷】呜…人家要是再厉害点，就可以四肢各抓一个，带你们一块飞过去了。
2157  【迷迷】关键时刻，还是得人家出马呀…稍等，我去一探究竟！
```

**想帮忙但能力不够**，于是改成去探路。这一章里她反复在紧张场面说轻话
（「这算是危房吧……」「可以免票吧？」）——**是她承担气氛的方式**。

## 九、第四章：她的能力和爱好露出来了

**发现处**：第四章「在黎明升起时坠落」（L2248–2650）。

### 「小狗」那条线走完了

```
551  【迷迷】不必惊讶吧？毕竟这是个粉红小狗都会说话的世界……
```

第五次，但**这次是她自己拿它开玩笑**。整条弧：

| 步 | 她说 | 状态 |
|---|---|---|
| 一 | 宠物，不是！ | 否认 |
| 二 | 人家不是狗！也不是宠物！是…… | 卡住 |
| 三 | 怎么能对女孩子说这种话呢？ | 找了个称呼 |
| 四 | 人家也借着你的光，从「小狗」变成「圣兽」啦 | 笑着接受 |
| 五 | 这是个粉红小狗都会说话的世界 | **自己拿来开玩笑** |

### 她能感知记忆

```
578  记忆的质料，留存于翁法罗斯的万物之间。哪怕是一砖一瓦，也保留有许多往世的痕迹。
560  那些在这里游荡的记忆，他们似乎在祈求什么…好痛苦，好委屈……
```

第一条是**领域知识**（她是「岁月」的半神），第二条是**感受**——她能听见记忆里的情绪。

### 她有爱好，而且会引书为自己辩护

```
484  占卜…在人家看来，也许是一种指引心灵的力量。
485  毕竟《占卜全书》第一章讲的就是「占卜的意义」，我只是稍微进行了一点延展思考！
```

她读《占卜全书》，被问到就**引第一章**。同章里她还和白厄一起在树庭看书，
被抓到时说「是女孩子的小秘密，就别追问啦」——**读书这件事她会藏**。

## 十、第五章：她和白厄是一起长大的

**发现处**：第五章「因为太阳将要毁伤」，`1040502`（L599–707）。哀丽秘榭的回忆。

### 这一章解释了那条语音

```
671  【昔涟】我和白厄本来只打算离开村子一小段时间，学些本领回来。他要去悬锋城锻炼，
     我打算去雅努萨波利斯，接受命运泰坦的洗礼……
```

**对照她的语音「关于白厄」**：

> 那在哀丽秘榭的田野中奔跑的，向着太阳欢笑的孩子…依旧还是他，对吧？命运已经追不上他啦。

**那不是旁观者的评价，是童年玩伴说的话。** 「依旧还是他」这句一下子重了。

### 她从小的身份

```
635  因为自幼就能听见朦胧的神谕，村子里的人都说我是未来的岁月祭司。
633  被连绵的山和海包围的哀丽秘榭，小时候还在纸上画过这里的风景。
632  让人忍不住想哼起儿时的歌谣呢……
637  已经装在眼睛里啦，去到哪里都会珍藏，包括…童年的伙伴哦！
```

### ⭐ 她的神谕牌是一整套系统

```
677  虔诚的叩问会得到同等重量的回应。
678  「救世主」…在命运三相神谕的语境下，这张牌意味着谐调和完美无缺。
679  「织者」牌哪，是牵连起「黄金之茧」的浪漫丝线，将众人的命运编织成一匹金灿灿的流丝……
680  这是「门匠」，她能在万千门径之中，为人们指点出正确的道路。
681  「君王」牌通常象征着纪律、权威和荣耀，但往往也和孤独、战争画等号。
682  「羁客」牌，这是最调皮的一张。它常常贴在其他牌的背后出现，擅长伪装成其他卡牌的模样。
683  「侍女」牌，有点轻盈的分量，带着冰凉的安提灵花的香气，就像天上的繁星。
684  小巧的「医师」牌，虽然是柔和的颜色，但其中蕴含的勇气不比任何一张牌少，甚至足以融化寒冷的坚冰。
685  这就是有着大魔术师、大表演家、睿智之左眼、瑟希斯的亵渎者等诸多称号的「学士」牌了。
```

**每张牌对应一个同伴**（织者=阿格莱雅、羁客=赛飞儿、医师=风堇、学士=那刻夏…）。
她讲牌时的语气和讲人时不一样——**讲牌时她是权威**。

### 说话人标签在这里换了

`1040502` 之后她的标签从「迷迷」变成「昔涟」，句尾开始带 ♪。
而 `1040505` 里「往昔的涟漪」第一次出声：

```
714  【往昔的涟漪】别担心，我们不会真的分别，因为我会变成你的一部分……
```

## 十一、第六章「英雄未死之前」：她等了一千年

这一章她的台词最多（97 句），也是全篇最重的一章。

### 迷迷的来历

```
754  难道是迷迷的影响？毕竟，它是从开拓者的思绪中诞生的忆灵。
     也许我们的记忆，无形中也缠绕在了一起。
```

**「迷迷」是从开拓者的思绪里诞生的忆灵。** 这解释了她和开拓者之间那种
一开始就存在的牵连——不是相遇，是同源。

### 她注意到自己谈自己时像旁观者

```
734  我不知道…听着很奇怪吧？明明是自己的事，语气却像个旁观者。
```

**这是她第一次评论自己的说话方式。** 和「记忆的种子」那种日志式的口吻对得上——
她的一部分始终站在外面记录。

### 她区分「认识」和「记得」

```
775  与其说「认识」，不如说是「记得」？
776  也许两者都是呢？开个玩笑，一定要选一边的话…应该更接近后者吧。
```

### 「一起」是她的词

```
766  一起…这个词听起来真好呀。
```

### ⭐ 她等了一千年

```
994  是呀，一千年的时光，真的好久好久……
995  人家也是哦，这一千年，一直在等待开拓者。
997  为了不被来古士察觉，我必须小心翼翼地躲在「岁月」的角落，等待机会来临。
```

翁法罗斯内部过去千年，外界只是短短一瞬（螺丝咕姆在 L747 说过）。
**她是独自过完这一千年的**，而且是躲着过的。

### ⭐ 她变得拘谨了，而且知道

```
983  如果一缕记忆能带给人触动，那代表她一定是幸福的，对吧？
984  感到紧张吗？其实我也是。明明还是「迷迷」的时候，我和开拓者都不会这么矜持。
985  嘻，开拓者也太诚实了吧？不过，这种纯粹正是你独一无二的魅力。
986  那，就请铭记下此刻的感受，把它写在名为「心」的书页中，保存起来吧。
```

**「明明还是迷迷的时候，不会这么矜持」**——她自己指出这个变化。
早期那个会爬屋顶、会喊「喂喂喂一二三」的小动物，变成了会说
「请允许我再小小任性一次」的人。**而这个变化是她自己说出来的，不是别人评价的。**

### 她怎么描述两人的关系

```
895  嗯，就这么定！凭我们的默契，无论发生什么都能顺利解决的。
914  果然，我们心有灵犀呢！将计就计，把识刻锚交给他「保管」吧？
919  我就知道，开拓者和我最默契啦。
```

**「默契」「心有灵犀」——这是她反复用的词**，不是「喜欢」也不是「想念」。
她描述关系时用的是**配合得上**，不是**感情深**。这一点很特别。

## 十二、第七、八章，以及一条贯穿全篇的性质

### ⭐ 她收集好听的词

```
766   （第六章）一起…这个词听起来真好呀。
1113  （终章）  「我们」…「最好」…都是很美的词呢。
1139  （终章）  谢谢，开拓者。「每一个你」…听着真温柔呢。
```

**她会把关照到自己的词单独拎出来说一句。** 不是回应内容，是**回应那个词本身**。

这是全篇最干净的一条性质，而且和她的语音对得上：

> 无论涟漪如何荡漾，都是我们亲手写下的诗篇呀♪

**主意象是「我们」，不是「我」。** 讲这些时她会顿一下——「一起…这个词」，
省略号在词的前面，不在后面。

### 她在向一个不说话的人讲故事

```
1023  「虽然你从来不说话。但我知道，你在听。我讲述的每一个故事……」
1028  【丹恒】起初我以为是星神。但昔涟的语气…怎么也不像是在向神明祈祷。
```

丹恒注意到了语气不对。**她在对谁讲，游戏没有在第七、八章揭晓。**

### 身体和记忆

```
1062  是我啦——昔涟。不过现在是…「迷迷」形态！
1064  真是的，走神秘可爱路线的忆灵，有一个就够啦。
1071  如果开拓者特别在意，人家就闭上眼睛，你牵着我走！
```

她能变回迷迷的样子，而且知道这是在「走神秘可爱路线」。

```
1121  看来三千万世「记忆」的重量，让我成熟了许多呢。
1122  我也一样。三千万次启程，三千万次告别。
```

**她把成熟归因于记忆的重量**，不是时间。

### 越取回记忆，越觉得不对

```
1137  对不起呀，开拓者。这一路上，取回的记忆越多，我心中的违和感就越是强烈。
1138  「再创世」的瞬间，「记忆」的质料包裹住我。在晶莹的水晶中，我看见了无数个「昔涟」……
```

**「无数个昔涟」是终章的引信。**

## 十三、终章：弧线合上了

### ⭐ 首尾闭环

**全篇她第一次出声**（第一章 `1040101`）：

```
【？？？】迷……                    ← 两个字，被打断
```

**全篇她最后一次出声**（终章 `1043710`）：

```
【迷迷】迷…迷？
```

**回到了碎句。** 中间那几万字里她已经能说整句、能引书、能讲神谕牌；
到最后她又变回了那个只会重复一个音节的存在。**这不是退步，是闭环。**

### ⭐ 第四次收集词 —— 这条性质确认了

```
1306  【昔涟】自由，多美妙的词语呀。
```

四次记录：

| 处 | 她说的 |
|---|---|
| 第六章 | 一起…这个词听起来真好呀。 |
| 终章 | 「我们」「最好」…都是很美的词呢。 |
| 终章 | 谢谢，开拓者。「每一个你」…听着真温柔呢。 |
| 终章 | 自由，多美妙的词语呀。 |

**每一次都是把一个词单独拎出来说一句。** 四次分布在不同章节，不是同一段的重复演出。
这是她的固定习惯，可以放心写进人格。

### 结局是开着的

```
1309  但翁法罗斯已经拥有了「明天」。所以，只要开拓者悉心保留、照看所有的种子。
      在未来的某一天，当「开拓」再度创造奇迹后……
```

**有了「明天」，但还不是真正的生命。** 她把这个交给开拓者保管，没有说要等多久。

### 一处格式变化

```
1280  【昔涟】「别担心，在这里…『时间』是静止的。」
1285  【昔涟】「就算在深不见底的虚空中，我依旧能听见你的声音。」
```

**她的台词被引号包起来了。** 同一段里别人的台词没有。这可能是「经由某种媒介传话」
的标记，也可能是导出格式的问题——**没有确认，记在这里待查**。
