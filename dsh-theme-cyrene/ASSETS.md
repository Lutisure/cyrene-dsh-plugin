# 素材投放说明 · ASSETS

把文件丢进下面这些目录就能生效。**正常情况下不需要重新构建**：宿主半在每次
请求 `/theme-cyrene-assets/manifest` 时实时扫描这些目录，客户端启动时读取该
清单，所以「放文件 → 刷新页面」就够了。

`node build.mjs` 只做一件事：把素材的 URL 清单预先写进 `lib/client.js`。
只有当你想要一个自包含、脱离目录也能用的包（例如要发布到 npm）时才需要它。

## 目录约定

| 目录 | 放什么 | 扩展名 |
|---|---|---|
| `assets/` | 壁纸（静态 + 动态），可建子目录分类 | `.jpg` `.jpeg` `.png` `.webp` `.avif` `.mp4` `.webm` |
| `music/` | 背景音乐 | `.mp3` `.m4a` `.flac` `.ogg` `.oga` `.opus` `.wav` |
| `music/figure/` | 歌曲封面（第一张作默认封面） | `.jpg` `.jpeg` `.png` `.webp` |
| `GIF/` | 开屏动画（取排序第一个） | `.gif` `.webp` `.png` |
| `GIF/emotes/` | 表情包，**文件名即触发情绪** | `.gif` `.webp` `.png` |

### 壁纸

- 文件名含 `Default`（不区分大小写）的那张，会在**首次安装**（无历史记录）时作为初始壁纸。
- 视频壁纸在网格里排在静态壁纸前面，并用 `<video preload="metadata">` 做缩略图 ——
  宿主半实现了 HTTP Range，所以这一步只拉取少量字节，不会把整个视频下载下来。
- 也可以完全不用这些目录：在界面里点「景」→「＋ 添加壁纸」运行时导入，
  文件会持久化到 `$DSH_HOME/theme-cyrene/uploads/wallpapers/`。

### 表情包

文件名去掉扩展名后就是**情绪键**，客户端按对话内容匹配：

| 文件名 | 触发词（命中任一即弹出） |
|---|---|
| `开心.webp` | 谢谢 / 太好了 / 太棒 / 厉害 / 绝了 / 感谢 / 辛苦 |
| `得意.webp` | 搞定 / 完成 / 成功了 / 已解决 / 通过了 |
| `没错.webp` | 没错 / 正是 / 确实 / 对的 / 就是这样 |
| `期待.webp` | 发我 / 提供 / 给我 / 发一下 / 贴一下 |
| `疑惑.webp` | 确认一下 / 要我 / 可以吗 / 是否 / 确定吗 |

规则表在 `lib/client/80-emotes.js` 的 `EMOTE_TRIGGERS`，想改触发词直接改那里。
每回合最多弹一个；没有 `GIF/emotes/` 目录时这套彩蛋完全不启用。

### 开屏动画

`GIF/` 里排序第一个文件即为开屏动画。**每次浏览器会话首次加载**播放一次；
在输入框发送 `SAM`、`昔涟` 或 `CYRENE` 可重播。系统若开启「减少动态效果」
则自动跳过。目录为空时不播放，也不会报错。

## 体积建议

素材不进 JS 包，由 `/theme-cyrene-assets/` 路由按需流式提供（配置了 Range，
支持拖动进度条）。仍然建议控制在合理范围以加快首屏：

- 图片 ≤ 500 KB，视频 ≤ 1080p，音频 ≤ 128 kbps

参考：把素材内联进 bundle 是同类插件踩过的坑 —— 那会把 `client.js` 从约 100 KB
推到 80 MB，进而让浏览器的组合加载器直接失败。`build.mjs` 因此设了 512 KB 上限，
超了会直接报错而不是产出坏包。（当前盘上的 `client.js` 是 390 KB / 399,312 字节。）
